# Map 3D visualization

I developed a graphic project, rendering 3D visualization of input map:

* Memory management and optimisation
* Implementation of Xiaolin Wu's line algorithm

---

### System Requirements

- Linux (Ubuntu)
- gcc
- make

---

### Build

```bash
git https://github.com/romolog/C__graphics__3D_visualization_2024 map_3d;
cd map_3d;
make;
```

### Run
```bash
./map_3d ./maps/1t.fdf;
```
